## 🔧 Mantenimiento - Página temporal

Se ha añadido una página de mantenimiento llamada `maintenance.html`. Para mostrarla como la página principal se ha reemplazado el `index.html` original. Se creó una copia de seguridad llamada `index.html.bak` en la misma carpeta.

Cómo restaurar la página original:

- En Windows PowerShell:

```powershell
cp .\index.html.bak .\index.html
```

Si necesitas que haga la restauración por ti o que ajuste los enlaces (email/Instagram) en la página de mantenimiento, dímelo y lo hago.
